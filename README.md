# 💰 Expense Tracker App

A sleek and interactive Expense Tracker built with HTML, CSS, and JavaScript. This app helps users keep track of their income and expenses, see a summary of their total balance, and maintain a transaction history. It's a great beginner-friendly project to understand DOM manipulation, event handling, and local storage in JavaScript.

---

## 🔍 Features
- Add income or expense with a name and amount
- View total balance, income, and expense
- Automatically updates on every transaction
- Delete individual transactions
- Stores data using **Local Storage**
- Responsive UI with modern gradient design

---

## 🛠️ Technologies Used
- **HTML** – Structure of the app
- **CSS** – Styling with gradients and responsiveness
- **JavaScript** – Functionality and local storage integration

---
🖱️ Usage
Enter a transaction name and amount.
Click "Add Transaction" to save it.
View updated balance, income, and expenses.
Use the ❌ button to delete unwanted transactions
